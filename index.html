Phonics for ages 3 to 7

Learn to read in a cozy house

Phonics House is a reading game set in a six-room clay dollhouse. In every room your child hears letter sounds, traces each letter, blends sounds into words like sun and cat, and reads short stories with Finn the Fox.

How your child learns

Each letter follows the same four steps, in the order children usually learn to read: sound first, then shape, then words.

  1. Hear the soundEvery letter is spoken as a pure phonics sound, with a picture word such as s for sun.
  2. Trace the letterUppercase and lowercase on handwriting lines, stroke by stroke with a finger.
  3. Blend wordsSnap letter sounds together to build short words like sat, tan and cat.
  4. Read a storyShort picture stories where your child fills in the missing words.

The letters come in a phonics-first order (S, A, T, N…), so children can read real words early. Things in each room start with that room's letters.

A short game for every step

Each letter has its own set of mini-games. These are real screens from the app.

Also in the house: Pop Bubbles, Listen & Find, Read & Match, Feed Finn, Numbers 1 to 10, and a Colors room with sorting, a color mixer and painting.

Two modes, one house

Pick an age when you set up the app. You can change it any time in the parents' settings.

Ages 3–4

Preschool

Ages 5–7

For parents

Built for young children using the app with, or near, a grown-up.

No ads, plays offline

There are no ads anywhere. Everything plays without an internet connection, so it works in the car or on a flight.

A parent gate

Buying, restoring purchases, redeeming a code and opening settings or outside links all ask for a three-digit code written in words.

Stays on the device

No accounts and no sign-in. Your child's name is optional and never leaves the device. See the privacy policy.

Free to try
